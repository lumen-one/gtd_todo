# 任务

所有任务都在**这一个文档**里，用 `# 标题` 分类，一条任务一行。
行格式：`- [ ] 任务名 创建 <日期,时间> 结束 <日期,时间> 完成 <日期,时间> 备注… ##标签`

内核属性（任务 id、工作强度、优先级、时间裕度、剩余工作量）在同目录的 `.gtd/<任务id>.md` 里，由应用维护。
这个文档归人所有：应用只改它自己写的那一行，其余内容一字不动。
