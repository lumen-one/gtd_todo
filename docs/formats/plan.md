# B.7 `编排.md`（今日编排的时间轴）

**一个文件装所有日子**，与 `主线.md` 同族：应用维护整份，Obsidian 里可读可改，读进来
的改动生效，保存时正文按模型重写。

```markdown
### 2026-10-22

- 08:30 晨会
- 09:30 项目评审
- 12:30 午餐休息
- 临时插进来的事

### 2026-10-21

- 09:00 晨会
```

- **日期段**：一行 `### yyyy-MM-dd`（写 `##` 也认）开头一段，段内一行一条。段与段之间
  按时间倒序排，应用写回时自己维持这个顺序；
- **一条 = 时刻 + 标题**：`- HH:mm 标题`。行首第一个词形如 `H:mm` / `HH:mm` 就当时刻
  （写回补零），否则整行都是标题、时刻为空；
- **行序就是顺序**：应用不按时刻重排，保存时也不排序——拖动只改行的先后；
- **同一天可以有重复的标题**：两条『午餐休息』是两条，不去重、不合并；
- 时刻越界（`25:00`）按"没有时刻"处理，原文留在标题里，不改写；
- **已知局限**（登记在此，不另做）：
  - 正文由应用重写：不属于日期段或条目行的自由文字，下次保存会消失；
  - 标题以时刻开头（把 `12:30 出发` 整句当标题）会被当成时刻——与 `tasks.md` 里的
    `创建` / `完成` 锚点是同一类边界；
  - 两个引擎同时改同一份文件按后写者胜（与 `routines.md`、`主线.md` 一致）。
