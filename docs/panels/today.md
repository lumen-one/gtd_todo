# 6.1 今日清单页

**分组连续编号**：

```text
⓿ 挂起组      挂起进行中的长期散件：无编号、置于本页最顶（逾期组之上）；
              组内可上下拖动调序；点一下 = 今天做过（退出本组，次日早上自动回来）；
              完成、或长按『不再每日挂起』才算彻底离开
① 逾期组      过截止未完成：无编号、橙红徽标置顶，完成/改期前不消失
② 开始型组  今天到点的开始型任务：按时间点升序，行右端给开始色时间签；组内不可拖（时间就是序）
③ 截止型组      今天该动手（裕度算出的提醒**锚点**落在今天）或今天到期的截止型任务：
              按调度优先级排序（裕度薄的在前，优先级作乘数）；可拖插队
              ——**无排序档下**：只收**今天到期**的（不跑算法，没有锚点这套准入），
              组内顺序 = 手动序
④ 例行组      周期任务当天实例：排在截止型组之后；不占工时、默认不响（设了响的到点走提醒）
⑤ 被挑散件    定期挑/手动挑的那一件：无提醒、仅可见（只在标准档出现，本页最后）
⑥ 散件段      三无散件，**仅无排序档**：本页最底；不编号、弱化呈现；
              可拖，但只改整理序（`pool_order`）；**搬去任务池的不在这一段**
              （`loose_home`，长按『移到任务池』）
```

- **标准档的条目由锚点决定，与响不响铃无关**：③ 组收"锚点落在今天"或"今天到期"的，
  顺序是调度优先级；『响铃』只管这条提醒出不出声。**无排序档是例外**：③ 只收"今天到期"
  的、顺序改手动，另外页底多出一段 ⑥ 散件段（任务池的散件段整体搬到这里），**⑤ 不出现**
  ——这一档不跑定期挑。
- **编号跨 ②③④ 组连续**（1、2、3…）；挂起组（⓿）、逾期组、被挑散件（⑤）与散件段（⑥）
  不编号（后两者弱化呈现）。无排序档下编号照旧连续，只是那一组的**编号 = 手动顺序**。
- **挂起进行**：长期散件（三无、默认'长期'）有一个专属动作
  **『挂起进行』**（长按菜单里，和别的动作同一份条目表）——
  点了它这件事就**顶到今日页最顶**的**挂起组**（⓿，在逾期组之上、无编号），
  表示"这件事每天做一点"：
  - **只有长期散件能挂**：有截止的事归调度管（[UI 文档](../ui-interaction.md) §7.1）。截止型一旦
    有了日期、或工时从'长期'换成数字（'转正'），它就不再是散件，**两个挂起标记一起自动清掉**
    ——~~'转正'后已挂的仍占着挂起位，直到完成或『取消挂起』~~ 撤销：那样的件既在 ⓿、又被挡在
    逾期/截止型组之外，调度在算、提醒会响，人却在清单里找不到它；
  - **点一下 = 今天做过**：挂起组是**唯一一个点按不是"看详情"的组**——点完它退出 ⓿、回原来的家
    （标准档回任务池散件段，无排序档回今日页 ⑥），**第二天早上自动重新挂上**。
    挂起不是"压在顶上直到做完"，而是"长期习惯、每天做一点点"；
  - **回挂的时机**是一天里的第一次运行：启动，或常驻时那 20 秒一次的跨日检查。**同一天里点掉
    再重启不会自己跳回来**（`in_progress_daily` 记着"今天做过"的日期）；
  - **可以同时挂多件**，组内**上下拖动调序**（和截止型组同一个拖把手）——挂起时刻只是排序的
    载体，拖动即整段重写、重启保留；自动回挂的那批按任务列表顺序叠在一起，当天手动挂的
    （时刻更晚）压在它们上面；
  - **离开每日循环**三条路：完成、长按『不再每日挂起』、或不再是散件（加截止 / 转正，见第一条）；
  - 挂起中的任务**从任务池两段隐藏**（和被挑散件同一规则：今日页顶置组是它唯一的显示位置），
    点掉（今天做过）之后回池子原处；
  - **两档调度模式下挂起组都在最顶、都能拖**——它是持久意图不是算法排序，无排序档
    也不把它并进手动序（与逾期组同列"四处不跟着变"的地位）。
- **上下拖拽 = 手动插队，只对截止型组生效**：手动顺序是**持久意图**（记在任务上）——
  被拖到前面的任务压在截止型组最上面，**保持到它完成**；其余截止型任务仍按调度排序。
  多件插队件之间**后插的在上**（栈式），插队件之间可再拖调整相对顺序。
  （**无排序档下**拖拽不再是"插队"而是"定序"：整组按你拖的结果排，算法不再插手。）
- **无排序档**（新装默认）：算法完全不参与这一页：
  - ③ 截止型组只收**今天到期**的（逾期的在 ① 组）。这一档没有锚点，也就没有"裕度薄、
    今天该动手"那类提前进来的任务——它们留在任务池，等当天到期才出现；
  - 顺序完全按**手动序**；没排过序的任务按**创建先后**排在后面（新建的从末尾开始，
    拖一下就有序了）；
  - **③ 组内可随意拖**：拖动即整段重编号、**重启保留**，拖完算法不会再把你排回去；
    长按菜单里那一项也跟着换成『移到最前』（同一个命令：整段重编号），
    而不是自动档那颗『插队到最前』——插队标记这一档不生效；
  - **三处不跟着变**（沿用上面的组号）：**① 逾期组**仍置顶（那是状态，不是排序）；
    **② 开始型组**仍按时刻升序、组内不可拖（时刻本身就是序）；**④ 例行组**仍按当天
    发生时刻升序（实例每天新生，没有手动序）。
    任务池的**计划段**也不变（仍按整理序，见 [任务池页](pool.md)）——变的只有散件段，见下一条；
  - **页底多一段 ⑥ 散件段**：池子里的三无散件整段列在这里，池子那边只留被你搬过去的
    那些（见下下条），不会两处重复。这一段**不编号**，拖动只改**整理序**
    （写 `pool_order`，与池子散件段同一个动作）——不碰 ③ 的手动序（`manual_order`），
    两套序号各管各的；
  - **这一档不跑定期挑**：散件本来就全在 ⑥，再挑一件"浮到今日"只是往同一堆里挪一格。
    『定期挑散件』与间隔在这一档都不生效（切回标准档按间隔照常挑），**⑤ 段随之
    不出现**；~~无排序档照旧挑，挑中的那件从 ⑥ 移到 ⑤~~ 一并撤销——那一档没有"挑上来"
    的去处；
  - **搬去任务池**：⑥ 段长按『移到任务池』，这一件就改住池子的散件段（metadata
    `loose_home: pool`），当日不再出现在 ⑥；在池子里长按『移到今日清单』搬回来。
    两个动作互逆、**长期有效**——不是"今天先收起来"，明天也不会自己回来。切档不迁移：
    标记只在无排序档参与，切回标准档时散件照旧全在池子；
  - **关掉的不只是排序**：这一档不跑公式，裕度、风险、"做不到"的提示、提醒节奏全都没有。
    提醒换成每件**截止前与截止各一次**（提前量默认 30 分钟，设置里可改），逾期不响；完成靠勾选，
    不做工时对账；列表行也**不标工时徽标**（那是缺省 30 分钟，标出来等于把隐藏值露出去）；
  - 切回**标准**时手动序**原样保留、只是不生效**，不会丢、也不用重新拖一遍；
    散件段回到任务池，今日页底那一段随之消失。
- **列表行**：左侧编号、标题、备注第一行（弱化）；**右端时间签**——同一天只写时刻
  `18:00`，**跨日的件只写日期** `10-30`（今年之内不带年；几点去详情卡看——`10-30 18:00`
  在 240dp 的行上要挤掉大半条标题），颜色取日历那套点色板：
  **开始型与例行 = 开始色，截止型 = 截止色**，逾期的那件整条转逾期橙红。没有日期的
  （挂起组的长期任务、被挑散件、散件段）不给时间签。标题后面只会多出两颗胶囊之一：
  **『裕度告急』**（标准档）与**『已推迟』**，出现时才占位。逾期不再叠一颗
  『已逾期』胶囊——① 组头、左侧红点、时间签颜色已经各说了一遍；工时与『插队』也不进
  列表行：插队由位置表达（压在组顶），工时在编辑表单里看。
- **点条目 = 详情卡**：卡里只有三样东西——标题、**一行时间**（前面一颗日历点色的圆点，
  文案是 `开始…` / `截止…` / `发生…` / `不排期`，已完成件再补一行 `完成 <时刻>`）、
  **备注全文**。没有属性表、没有调度派生量、也没有动作按钮：**点击只看，长按才做**，
  卡本身永远只读。七个组与池子两段都走这一份卡，**只有 ⓿ 挂起组例外**——
  那里点一下 = 今天做过（见上），不弹卡。
- **长按条目弹菜单**：完成 / 推迟（档位见 [UI 文档](../ui-interaction.md) §7.2）/ 编辑 / 删除（软删除，见下文『完成后』）；最后一行 **『多选』** 进选择模式（跨页保留、动作固定为完成/删除，[面板与页面](README.md)『多选』）。
  『编辑』与新建第 2 页**同一套字段**（[UI 文档](../ui-interaction.md) §5.1）：
  **编辑态 = 属性展开表单**（显式控件直改类型/日期/工时/备注，改完调度自动重锚）；
  新建是先问日期再进这张表单——两处都是显式控件，创建流程里已无手势。
- **菜单按组上下文相关**：
  ⓿ 挂起组 = 完成 / **『不再每日挂起』** / 编辑 / 删除，**无『推迟』**（长期任务没有截止，没有可推迟的
  余地），也**不单列『今天做过』**——点一下就是它；
  ② 开始型组的『推迟』= snooze 本次提醒（事件时刻不变，走 D8 档位）；
  ④ 例行实例 = **完成**（今日完成，次日再生）/ **跳过今天**（不完成，今日不再显示）/
  **编辑规则**（跳设置页定位到该规则，不提供"编辑实例"——实例是临时的）/
  **删除规则**（需确认，从 routines.md 移除），**无『推迟』**（实例默认不响，改节奏去编辑规则）；
  ⑤ 被挑散件 = 完成 / **放回池子** / 编辑（展开表单，可顺手转正）/ 删除，
  **无『推迟』**（没有日期可挪，"放回池子"承担"今天不想做"的语义）；
  ⑥ 散件段 = 完成 / 『挂起进行』（仅长期散件）/ 编辑 / 删除 / **『移到任务池』**
  （仅无排序档，互逆动作在 [任务池页](pool.md)），**无『推迟』**（无日期）、
  **无『挑到今日』**（它已经在今日页）。
- **完成后**：人类文档里那一行**原地**把 `- [ ]` 改成 `- [x]` 并补 `完成 <日期,时间>`
  （内核属性文档同步落 `status: completed` 与 `completed_at`；**长期任务没有内核属性可同步**——它的内核文档只有 id，完成只落在人类文档那一行），**这一行与其余内容
  原样保留**（Obsidian 里可翻历史），各清单立即消失——可在『已完成』页找回并恢复
  （[已完成页](completed.md)）；灵感文件与此无关，**不动**（它在自己的页里改，[灵感页](notes.md)）。
  **删除** = 内核属性文件移入 `.gtd/.trash/` + 那一行用 `%%…%%` 注释掉（可捞回，见 [UI 文档](../ui-interaction.md) §4.3）。
- 除灵感页外的每页右下角都有两个按钮：**添加待办**（「+」，进 [UI 文档](../ui-interaction.md) §5.1 对话框）与**日历**（「日历」，[日历弹窗](calendar.md)）。**选择模式下这两个钮让位给一条批处理条**（同上）。


## 顶部日期行

日期那一行的右端有一颗**支线**按钮（分叉图标），点开是编排那一块覆盖页的支线视图
（[支线](branch.md)）。日期仍是 `10 月 25 日 · 周日` 一整行，按钮贴右端、不压字；
240dp 上也放得下两者。

## 与今日编排的关系

- 这一页下面还有一层：**到顶之后再往下拉**，今日编排从面板顶边滑下来
  （[今日编排](plan.md)）。默认页设成今日清单、今天又排过编排时，**每次展开面板**
  都先亮编排（收起再拉会再亮）；没有编排、或默认页是别的页，就还是这一页。
  出来那一下是镜像的：编排的时间轴**滚到最底再继续上滑**就推回这一页。
- 两边互不改编：编辑清单不动编排，改编排不动清单——理由见
  [决定](../decisions/2026-10-22-today-plan.md)。
- 选择模式下不接下拉：手上正拿着"选中"这个意图，下拉只会误触（[面板与页面](README.md)『多选』）。
