# 6.11 今日编排（今日页下拉 → 时间轴覆盖页）

**一句话**：今天准备几点做什么，排成一条时间轴。它只管**排**，不管**做**——完成、
逾期、提醒都还在今日清单里。

## 入口：到顶之后再下拉

- 今日清单**已经滚到顶**，继续往下拉 → 覆盖页从面板顶边滑下来。跟手 1:1，松手时
  拉过 72dp 或快甩（≥500 px/s）补满，没够就弹回（与把手的阈值同一套，见
  [把手与面板](handle.md)）。
- **只认"到顶那一下的继续下拉"**：列表没到顶时下拉就是普通滚动；鼠标滚轮与触控板
  （`dragDetails` 为空）不算数。桌面壳靠**按住鼠标拖到顶再往下拖**——今日页那一处
  局部放开鼠标拖拽，别的列表不动。
- **今日页顶部没有常驻入口行**：只有日期那一行。代价是这条手势没有视觉线索，补偿
  放在首次引导的一步里（[侧边栏](README.md) 的"空状态与首次引导"）。
- 今日清单为空时也要能进来：空态本身是可滚的列表，不是居中的一块。

## 覆盖页

- 盖住整块面板（含面板头与页序圆点），与主线同一套呈现（[主线覆盖页](mainline.md)）。
  **页序仍是四页**，编排不是第五页（[侧边栏](README.md)）。标题行：
  `[返回] 今日编排 · 10 月 22 日`。
- 退出 = 左上『返回』+ 系统返回键。**不做上滑退出**——编排页里上滑就是滚时间轴。
- 桌面左栏共用同一个面板，进出与安卓一致。

## 时间轴

一条竖线串节点，从左往右读：左侧时刻、右侧标题块。

- **已过的时刻**：时间文字弱化。只是显示，不改状态，也不影响别处。
- **倒挂**（时刻比上一条早）：时间标橙。拖动只改行序、不改时刻，两者会打架——标出来
  就够了，不自动纠正、不弹窗、不阻止。
- **没有时刻**：条目可以只有标题，时刻列显示 `—`；它留在自己的行序上，不挪到末尾。

## 添加、拖动、编辑

- **添加**：末条之后一行细边框的『＋ 添加一项』，不做悬浮加号。点了就地展开标题与
  时刻两个输入，回车提交，那一行留在原位，可以连着写。时刻默认 = 上一条 + 30 分钟；
  没有上一条就取当前时刻向上取整到半点；清空 = 没有时刻。
- **拖动**：长按整条拖动（不放拖把手——一行只有时刻和标题，没有多余位置）。只改
  行序，松手整份重写一次（一次落盘 + 一个事件）。
- **编辑 / 删除**：点条目开一张轻量面板，改标题、改时刻、删除三个动作。
- **不做完成勾选**：完成只在今日清单做。编排是"排"，不是第二本完成账。

## 只管今天

- 界面只有今天，不设日期切换。跨天（应用活着跨过零点）自动落到今天的空轴。
- 昨天那份留在文件里，不主动清，也不在界面回看。

## 与今日清单的关系

两条时间轴各走各的：『固定时点组』是必须到点的硬约束（[今日清单页](today.md)），
编排是"我打算几点做"。**不联动**——编排里的一行不改任务、不进调度、不占工时、
不响提醒。想在时间轴上看到一场会，就自己写一行。

数据在 `tasks/编排.md`（[编排文件格式](../formats/plan.md)）。
