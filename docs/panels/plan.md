# 6.11 今日编排（今日页下拉 → 时间轴覆盖页）

**一句话**：这几天准备几点做什么，排成一条时间轴。它只管**排**，不管**做**——完成、
逾期、提醒都还在今日清单里。

## 入口：到顶之后再下拉

- 今日清单**已经滚到顶**，继续往下拉 → 覆盖页从面板顶边滑下来。跟手 1:1，松手时
  拉过 72dp 或快甩（≥500 px/s）补满，没够就弹回（与把手的阈值同一套，见
  [把手与面板](handle.md)）。
- **只认"到顶那一下的继续下拉"**：列表没到顶时下拉就是普通滚动；鼠标滚轮与触控板
  （`dragDetails` 为空）不算数。桌面壳靠**按住鼠标拖到顶再往下拖**——今日页那一处
  局部放开鼠标拖拽，别的列表不动。
- **今日页顶部没有常驻入口行**：只有日期那一行。代价是"第一次怎么进去"没有视觉线索，
  补偿放在首次引导的一步里（[侧边栏](README.md) 的"空状态与首次引导"）。编排里有内容
  之后就不用记这条手势了——默认页是今日清单时，展开会先亮编排（下一节），手势退成
  "从清单回编排"。
- 今日清单为空时也要能进来：空态本身是可滚的列表，不是居中的一块。

## 默认页是今日清单时，每次展开先亮编排

- **展开面板就亮**：设置里的默认页是今日清单、今天又排过东西，面板一拉出来就先显示
  编排（等于替你拉了一下）。今天没排就还是清单：空的那一份正是要去写的时候，先盖
  一层空轴只会挡路。
- **在面板露面之前就立起来**：宿主先亮覆盖页、再让面板出现（悬浮窗那一路是跟手拖出
  的起手那一拍），所以第一帧就是编排。反过来（面板先开、帧后再亮）露出的第一帧是今日
  清单，随后才被覆盖页盖上——那一下"先清单、再切成编排"是要避免的。同理，从关到开
  这一步**不播覆盖页的进场动画**：它底下露着的是今日清单。
- **每次展开只亮一次**：亮着的时候不会叠；按返回就是清单，这一轮里滑走再滑回也不弹。
  **收起面板再拉出来，又亮一遍**——"拉出来就看我的安排"说的是这一次打开，不是
  "今天看过了就不再给你看"。
- **默认页不是今日清单就不触发**：默认页设成灵感 / 池子 / 已完成时，展开落在那一页，
  那里有你要看的东西；要看编排就滑到今日清单再下拉（[侧边栏](README.md)『展开后
  默认落在哪一页』）。
- 点通知定位进来的不盖：定位优先，落在被点的那一件上。
- **桌面不接**：左栏常驻、没有"展开面板"这一步，切到今日页也不自动亮，要编排就下拉
  （[桌面壳](desktop.md)）。

## 覆盖页

- 盖住整块面板（含面板头与页序圆点），与主线同一套呈现（[主线覆盖页](mainline.md)）。
  **页序仍是四页**，编排不是第五页（[侧边栏](README.md)）。页头两行：第一行左上『返回』
  加标题「编排」、右端「N 项」；第二行是日期轴的三段标签（下一节）。**页头不写「今日编排」**
  ——这一页同时装昨天和明天，带「今日」的标题在别的那两页上是错的。
- 退出三条路：左上『返回』、系统返回键、**时间轴滚到最底再继续上滑**。
  上滑只在"末尾之后"算退出：滑到最底之前每一寸都是滚动，到了底才轮到退出——判据是
  位置不是手速（与今日页"到顶再下拉"是同一条规则的两端），所以不存在"想滚到底、
  结果退出去了"。跟手推回，松手时上推过 72dp 或向上快甩（≥500 px/s）才关，
  没够就弹回。~~不做上滑退出——编排页里上滑就是滚时间轴。~~ 撤销：当初拒的是
  "任意位置上滑都算退出"，那确实只能靠位置和速度去猜；限定在末尾之后，滚和退
  不再抢同一个位置。
- 桌面左栏共用同一个面板，进出与安卓一致。桌面的 overscroll 要靠按住鼠标拖出来
  （滚轮滚到头继续滚是常态，不认），所以这一页的列表在桌面也要放开鼠标拖拽。

## 日期轴：昨天、今天、明天

- 覆盖页内部是三页横滑，**打开永远落在今天**。日期轴只有昨天 / 今天 / 明天，不往外扩：
  更远的将来等它变成明天，更早的留在文件里但不回看。
- 翻页两条路：左右横滑，或者点页头第二行的三段标签。**标签不是手势的补充，是给桌面的**
  ——Windows 上横滑没有肌肉记忆，只有手势等于没有入口。主线记录页"翻页只点页头"是同
  一条道理（[主线覆盖页](mainline.md)）。
- 三段标签等分页宽：`昨天 22` / `今天 23` / `明天 24`（数字是当月的日），当前那一段用
  强调色加下划线，点即跳。
- **昨天只读**：条目照常按时间轴渲染，但没有『添加一项』、不能长按拖动、点条目不弹编辑
  面板，「N 项」旁边挂一枚锁。昨天是"当时打算怎么做"的记录，能改就成了第二份计划。
- **『现在』游标只在今天页**：昨天整天都过了、明天还没开始，两者都没有"现在"的位置。
  已过时刻的弱化同理，只在今天页生效。

## 时间轴

一条竖线串节点，从左往右读：左侧时刻、右侧标题块。

- **顺序就是时刻顺序**：改一条的时刻、或者新增一条，当天整条轴按时刻升序重排——同一
  时刻的保持原相对顺序，没有时刻的沉到最后。**唯一的手动例外是拖动**（下一节）：拖出来
  的顺序保留到下一次改时刻或新增为止。
- **现在**：竖线上有一道游标——左侧写『现在 14:32』，横线穿过标题块，落在
  "第一个时刻晚于现在"的那一条之前。游标**以上**的竖线用强调色（这段已经过完了），
  以下保持分隔线的灰：两样合起来就是今天过到哪儿的进度。
  行距是等距的（不为时长做缩放），所以游标按**条目**定位、不按像素插值——它只在
  跨过某一条的时刻往前走一格，不会随分钟缓慢移动。等距轴换来的好处是文字多少不
  影响节奏、拖动时行高不跳。
- **打开就把镜头落到『现在』**：今天这一页每次露面时滚到游标处，游标停在视口上方
  三分之一，前面留一小截已过的、后面露出还没到的。排得长的日子一打开就停在开头，
  等于先看一段早就过完的安排。昨天那页不动（它没有"现在"），明天那页也不动。
- **已过的时刻**：时刻与标题**一起**压淡（同一个色值），界线就是那道游标。只压字、
  不压底色——铺淡一层会让"已过"看着像"被划掉"。只是显示，不改状态，也不影响别处。
- **倒挂**（时刻比上一条早）：时间标橙。改时刻与新增都会重排，所以倒挂只剩两个来源：
  在 Obsidian 里手改文件、以及手动拖出来的顺序。标出来就够了，不自动纠正、不弹窗、
  不阻止——下一次改时刻或新增会把它拉回时刻序。
- **没有时刻**：条目可以只有标题，时刻列显示 `—`。它没有可比的点，重排时沉到最后，
  彼此保持原相对顺序，也不参与游标定位（游标只跟有时刻的那几条比）。

## 添加、拖动、编辑

- **添加**：末条之后一行细边框的『添加一项』（加号图标 + 文案），不做悬浮加号。点了
  就地展开标题与时刻两个输入，回车提交，那一行留在原位，可以连着写。时刻默认 =
  **最近一条有时刻的** + 60 分钟（末条没有时刻就往前找）；一条都没有时：今天取当前时刻
  向上取整到半点，**明天取 09:00**（晚上排明天，"现在"落上去没有意义）；清空 = 没有
  时刻。**输入框不写占位提示**——窄面板上"几点做什么"只剩半个字，看不清反成噪音；
  左边是时刻、右边是确定，上下文已经够了。
- **添加可以直接贴已有的任务**：添加行展开后，下面列出**今日清单**（按清单顺序）与
  **任务池**（计划段、散件段）的任务标题，最多六条，输入框里的字用来筛。点一条就直接
  落一条编排——时刻用当前默认，所以可以连点连排。编排里已有同名条目时，那条候选右侧
  标一个勾（标着也还能点：一天做两次同一件事是允许的）。
- **贴的是文字，不是引用**：不记任务 id、不写 metadata、不改任务，所以任务改名、改期、
  完成之后编排那一行原样不动。这是"编排条目不是任务"的同一件事
  （[决定](../decisions/2026-10-22-today-plan.md)），不是待修的耦合。
- **拖动**：长按整条拖动（不放拖把手——一行只有时刻和标题，没有多余位置）。只改
  行序、不改时刻，松手整份重写一次（一次落盘）。新序在松手那一格就定住，不等落盘
  回来（写盘是"读整份 → 改一天 → 整份写回"，等它回来的话会先弹回原位、写完再跳到
  新位，看着像来回闪）。这是唯一能盖过时刻顺序的操作，下一次改时刻或新增就会把它
  打回时刻序。
- **编辑 / 删除**：点条目开一张轻量面板，改标题、改时刻、删除三个动作。
- **不做完成勾选**：完成只在今日清单做。编排是"排"，不是第二本完成账。

## 跨天与留存

- 应用活着跨过零点：三页按新的当天重算，下次打开落在新的今天页。
- 编排按天分段存着，昨天那份留在文件里不主动清，更早的也在（Obsidian 里可读可改）。

## 与今日清单的关系

两条时间轴各走各的：『固定时点组』是必须到点的硬约束（[今日清单页](today.md)），
编排是"我打算几点做"。**不联动**——编排里的一行不改任务、不进调度、不占工时、
不响提醒。想在时间轴上看到一场会，就自己写一行。

数据在 `tasks/编排.md`（[编排文件格式](../formats/plan.md)）。
