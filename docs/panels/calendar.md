# 6.4 日历弹窗

- 入口 = 面板右下角的小按钮（原『～』堆三无的位置，v1.22 起），四个页面都在；
  点开弹出**月历**，有任务的日子打点。
- 点某天 → **当天列表从弹窗底部下滑展开**（同一弹窗内联动，**不再叠一层弹窗**）。
- 当天列表里可直接**改某任务日期**（点条目即改期），改完调度自动重锚（事件驱动，
  符合防 Zeno 规则）。**这里是详情卡的例外**：日历不属于侧边栏这四页，点条目仍是改期，
  不弹详情卡。
- **改期的适用范围**：可推/不可推任务可改；**例行实例只读**（在其发生日打点，
  点开提供『编辑规则』跳转）；散件与被挑散件无日期，不进日历。
- **与主线『记录』页不是同一个日历**：这里是**全局任务日历**（看哪天到期、就地改期）；
  主线覆盖页里那个日历画的是**主线的行为链流水与圈**（[主线覆盖页](mainline.md)），两处互不相干——任务日期
  不画进主线记录页，主线的圈也不进这个弹窗。
