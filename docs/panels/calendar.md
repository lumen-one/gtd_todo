# 6.4 日历弹窗

- 入口 = 面板右下角的小按钮，四个页面都在；
  点开弹出**月历**，有任务的日子打点。
- 点某天 → **当天列表从弹窗底部下滑展开**（同一弹窗内联动，**不再叠一层弹窗**）；**切月清空当天选中**——展开的当天列表收回去，回到"点某一天看当天安排"。
- 当天列表里可直接**改某任务日期**（点条目即改期），改完调度自动重锚（事件驱动，
  符合防 Zeno 规则）。**这里是详情卡的例外**：日历不属于侧边栏这四页，点条目仍是改期，
  不弹详情卡。
- **改期的适用范围**：可推/不可推任务可改；**例行实例只读**（在其发生日打点，
  点开提供『编辑规则』跳转）；散件与被挑散件无日期，不进日历。
- **与主线『记录』页不是同一个日历**：这里是**全局任务日历**（看哪天到期、就地改期）；
  主线覆盖页里那个日历画的是**主线的行为链流水与圈**（[主线覆盖页](mainline.md)），两处互不相干——任务日期
  不画进主线记录页，主线的圈也不进这个弹窗。
- **左右横滑切月**：月历区本身就是横向翻页的——往左滑看下个月、往右滑看上个月；两侧箭头保留（一次一格），点箭头与横滑是同一个动作的两种走法。横方向在弹窗里原本空着（当天列表只吃纵向），不与其他手势抢。
- **月历网格固定六行高**：月份有 4/5/6 行，翻页时高度不跟着变（4 行的月份底部留一截空白）。高度跟着月份变会让整块弹窗在滑动中跳，换来的只是"这个月没排满"看起来空一点。
