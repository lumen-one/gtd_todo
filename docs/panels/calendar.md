# 6.4 日历弹窗

- 入口 = 面板右下角的小按钮，灵感页以外都在；点开弹出**月历**，有安排的日子打点。
- 点某天 → **当天列表从弹窗底部下滑展开**（同一弹窗内联动，**不再叠一层弹窗**）；**切月清空当天选中**——展开的当天列表收回去，回到"点某天看安排，长按某天加一件"。
- **长按某天 = 直接在那天加一件**：当天列表顶部升起一行输入框（左侧标着这一天），敲标题、回车（或点行尾的勾）即落账，不叠对话框。落的是**截止型任务**，截止 = 该日 18:00，与[新建流程](../ui-interaction.md)里截止型的默认时刻同一档；要别的时点就从那件任务的编辑里改。加完输入行收起，当天列表立刻能看到新加的那件。**主路径不变**：右下角『+』仍是完整的创建流程（三无 / 截止型 / 开始型 三选一），长按只是日历里的快捷方式。
- 当天列表的行右端给**时间签**（与今日清单同一套：开始色 / 截止色、逾期转橙红，
  见[视觉规范](../ui-interaction.md) §8）——这一页整页都在说同一天，日期是废话，时刻才是新信息。
- 当天列表里可直接**改某任务日期**（点条目即改期），改完调度自动重锚（事件驱动，
  符合防 Zeno 规则）。**这里是详情卡的例外**：日历不属于侧边栏这四页，点条目仍是改期，
  不弹详情卡。
- **打点三色，按任务类型分**：开始型（`fixed`，含例行实例的发生）= 开始色；截止型（`flex`）
  = 截止色；**已经干完的 = 完成色**（暖灰，不分类别——干完这件事盖过类型本身）。一天最多
  三点，从左到右 开始 → 截止 → 完成。色值不写死在这里：它们随主题预设换，见
  [视觉规范](../ui-interaction.md) §8 的日历点色板。
- **三色是三层深浅**：截止最重、开始居中、完成最淡——白卡上是 6.2 / 4.5 / 3.6 的对底对比，
  深卡反过来（变亮才是变重）。这层明度差让三点在灰度截图与色弱视角下仍然分得开。
- **选中那一格不画开始点**——整颗圈是强调色填充，开始点跟它同族、贴上去连成一片，而下面
  展开的列表本来就在说这天有什么；截止点与完成点照画。已完成的条目排在当天列表末尾：弱化 +
  删除线 + 勾，不可点——改期对已完成的件没有意义，要恢复去已完成页。
- **过去的那些天照画，不按今天划线**：干完的活留在它到期的那一天，翻回上个月照样看得见
  那天做了什么——这就是日历的回顾。欠活的点也一样：过去到期、至今没干完的活，欠账还亮着。
- **改期的适用范围**：截止型/开始型任务可改；**例行实例只读**（在其发生日打点，
  点开提供『编辑规则』跳转）；散件与被挑散件无日期，不进日历。
- **与主线『记录』页不是同一个日历**：这里是**全局任务日历**（看哪天到期、就地改期）；
  主线覆盖页里那个日历画的是**主线的行为链流水与圈**（[主线覆盖页](mainline.md)），两处互不相干——任务日期
  不画进主线记录页，主线的圈也不进这个弹窗。
- **左右横滑切月**：月历区本身就是横向翻页的——往左滑看下个月、往右滑看上个月；两侧箭头保留（一次一格），点箭头与横滑是同一个动作的两种走法。横方向在弹窗里原本空着（当天列表只吃纵向），不与其他手势抢。
- **月历网格固定六行高**：月份有 4/5/6 行，翻页时高度不跟着变（4 行的月份底部留一截空白）。高度跟着月份变会让整块弹窗在滑动中跳，换来的只是"这个月没排满"看起来空一点。输入行升起时键盘会占掉下半屏，格子高度按可用高度再夹一道——键盘之上仍要看得见月历与输入行。
