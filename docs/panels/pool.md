# 6.3 任务池页

- **行右端给日期**（`10-28`，跨年写成 `27-01-05`）：颜色取日历那套点色板，开始型 = 开始色、
  截止型 = 截止色。**只给日期不给时刻**——这一页问的是"哪天"，几点归今日清单；
  三无散件没有日期，不给。
- **点条目 = 详情卡**：与今日清单同一张卡（[今日清单页](today.md)）——只读，只有标题、
  时间与备注；挑到今日 / 完成 / 编辑 / 删除都在长按菜单里。计划段与散件段同款。
- **条目操作（长按菜单，散件段与计划段同款）**：**挑到今日**（不转正，附今日尾部，
  当日手动挑标记生效，自动挑让位）/ **转正**（走 [UI 文档](../ui-interaction.md) §5.1 对话框补属性，进调度）/
  完成 / 编辑 / 删除（软删除）。**长期任务（三无散件）还多一个
  『挂起进行』**：顶到今日页最顶的挂起组，保持到完成或主动取消；
  挂起中的件在池子两段都不再出现（它的显示位置只在今日页顶置组）。
  **无排序档下散件段换一套**：没有『挑到今日』（这一档不跑定期挑，散件本来就在今日页），
  换成**『移到今日清单』**——清掉 `loose_home`，这件回今日页 ⑥。
- **上下拖拽**：仅为整理位置方便看（无调度含义）；**顺序持久化**——显示序记在任务
  metadata，重启保留；新建任务进对应组末尾。
- **任务池不受调度模式影响**，**唯一例外是散件段**：无排序档下散件默认列在今日页底部
  （[今日清单页](today.md) ⑥），池子这边只显示**被你搬过来的**那些（`loose_home: pool`，
  在 ⑥ 长按『移到任务池』）——同一件仍然只有一个家。
  池子其余部分在三档下都按**整理序**——手动整理过的在前（`pool_order`），
  其余计划段按截止升序、散件段按创建时间，周期条目按发生日期升序插入对应位置。
  这里的拖动与今日 ③ 是两套序号（`pool_order` vs `manual_order`），互不干扰。
- **空状态**："池干水清"；无排序档下若计划段也空、散件全在今日页，
  显示"散件都在今日清单底部"。
- **一条横线分两段**：
  - **横线前（计划段）**：明天、后天……未来要做的任务（截止型任务 + 未来的开始型）；
    **周期任务按下一次发生日期升序插入对应位置**（设置里提供"是否显示"开关）；
  - **横线后（散件段）**：三无散件；**无排序档只剩搬过来的那些**（其余整段在今日页
    底部，见上条）。
- **散件转正**两条路：
  1. **闲时手动**：长按散件选『转正』→ 走 [UI 文档](../ui-interaction.md) §5.1 对话框补属性（分类/截止/工时，即把'长期'换成具体工时）→ 进调度；
  2. **定期挑**（自动）：间隔可设置，**默认一天**；**随机**挑一件附到今日清单尾部，不响提醒只可见。
     细则：每天**独立随机**；昨天没做完的件**回池子重新参与随机**（不优先续挑）；
     你**手动挑过**的日子，当日自动挑就让位——今日尾部**最多一件散件**。
     **无排序档不跑**：那些件本来就整段在今日页 ⑥，再挑一件只是同一堆里换个位置；
     切回标准/完整档按间隔照常挑。
- **多选**：长按菜单最后一行『多选』，进选择模式后点条目即勾选；选中跨页保留、动作固定为完成/删除，勾选态的呈现与退出规则见 [面板与页面](README.md)『多选』。
