## 跨页共用：页序、默认页、面板头

- **四页结构，左右横滑翻页**：页面区横向拖动即翻页，与列表的纵向滚动是
  两个方向、互不抢手；圆点同时也是**跳转靶**——点哪个跳哪页（页序指示即可点的按钮）。
- **翻页从面板内部起手**：贴着屏幕最边缘那一小条是系统返回手势的地盘，
  从那儿横拖可能先被判成返回 / 收起面板；往面板里挪一点起手就是翻页。
- **不做纵向翻页**：竖滑手势和"浏览清单"抢的是同一个纵向手势区，代价就是翻不动。
  唯一的纵向越界是今日页**到顶之后**的继续下拉——它进的是编排覆盖页，不换页序
  （[今日编排](plan.md)）；反向那一下是覆盖页里**滚到底之后**的继续上滑，退回原来那页。
- 页序（**全文唯一定义处**）：**灵感 → 今日清单 → 任务池 → 已完成**——今日清单
  退到第二页：默认落点可配（下条），"打开就是今日"不是唯一正确姿势。
  文档与代码里的页面引用一律只认**页名**，不写"第 N 页"——页序改一次就要全库改数字的写法，
  上一轮已经吃过一次亏；
- **展开后默认落在哪一页**（设置项，[UI 文档](../ui-interaction.md) §9 第 12 条）：拖动把手展开时停在设置里选的那一页，
  默认**今日清单**——默认页是今日清单且今天排过编排时，每次展开先把编排亮出来
  （[今日编排](plan.md)）；**跟手拖出的那几帧就落在这一页**（起手页跟着设置走，不是松手补满后才跳过去）；点通知定位时按定位目标翻（今日件 / 池子件 / 已完成件），**定位优先**于这个
  默认值。落 `settings.json` 的 `default_page`，存的是页的稳定 id（`today` / `notes` / `pool` /
  `completed`）——与页序无关，将来再调顺序，旧设置仍指向同一页；
- 把手与面板互斥显示：展开时把手让位、收起后把手回来；应用自身在前台时两者都收起
  （此时走应用内把手 + 应用内面板）；
- **面板头两行**：
  - 第一行：页名（左）+ 右上角『设置』（应用内壳不显示这个按钮——App 主体就是设置页）；
  - 第二行：**当前主线名**——小链条图标 + 名字 + 进度（`3/7`），**整行可点**，点开主线的
    覆盖页（[主线覆盖页](mainline.md)）；没有主线时显示灰字『＋ 新建主线』。名字超长按省略号截断（窄面板
    240dp 上也有大半行），点开覆盖页看全名；
  - 为什么另起一行、不挤在页名右边：两个名字抢一行，240dp 上必有一个被截成三四个字。
    页名是"我在哪一页"（圆点兜底），主线名是"我在干什么"（没有替代品），后者值得这 20dp；
  - **面板头不摆『隐私』『关闭』两颗图标**：隐私那套改由快记承担（[快记](quick-note.md)），
    关面板靠点遮罩、系统返回键，以及尺寸固定后那条收起把手——三条路都不需要一颗常驻
    图标，而窄面板上每少一颗图标，页名就多留一截。**代价**：面板已经开着、旁边忽然来人
    时没有"一键清屏"，只能先收起面板再决定要不要记——不为这个低频场面常驻一颗按钮；
- 进应用的唯一入口：面板头『设置』与实例菜单『编辑规则』。

## 跨页共用：多选

- **入口 = 长按菜单的最后一行『多选』**：三个有任务条目的页面（今日清单 / 任务池 / 已完成）的菜单与例行实例菜单都有它，**详情卡里没有**。它是模式切换不是命令（不产生任何数据变更），所以不进 `taskMenuEntries` 那份共享条目表——那张表装的是命令，长按菜单与详情卡底部按钮同源；详情卡是"看单件"的场景，也不该出现批量的入口。放最后一行是不打乱肌肉记忆（『完成』永远是第一行）。
- **选中跨页保留**：选择模式属于**整块面板**，不是某一页——横滑翻页不清空选中（一次收拾"今日剩的 + 池子里堆的"是主要场景）。动作固定两颗，不随页换：**『完成』的计数只数未完成的**（已完成页选中的东西不能再完成，计数为 0 时按钮不可用），**『删除』数全部**。
- **选择模式下的条目**：左侧编号位换成圆形勾选、右侧拖把手不渲染（那一段因此不可拖），点条目 = 勾选 / 取消勾选，不再弹详情卡；长按不做任何事。今日页的下拉进编排（[今日编排](plan.md)）在这一模式下也不接——手上正拿着"选中"这个意图，下拉只会误触。
- **右下角换一条**：两个浮出钮（『+』新建 / 『日历』）让位给一条批处理条——『取消』+「已选 n」+ 完成 + 删除，同一位置，不另起一行。两颗动作按钮各带计数。
- **退出**：点『取消』，或成功执行完一次批量动作。删除仍是软删除 + 撤销 toast，一次删多件时撤销恢复这一批；批量完成不进回收站，反悔去『已完成』页逐条恢复。
- **已完成页只给删除**：批量恢复未完成不做——恢复后条目散回各页，误触的代价比"删了再去回收站捞"高。

## 跨页共用：右下角双钮

- 四页里**只有灵感页不摆**：那是读正文的地方，两颗钮压在字上，那一页也没有可加的东西
  （[灵感页](notes.md)）；要新建从别的页进。
- **上滑就藏**：列表往上推（手指上滑）累计过 12dp，两颗钮下滑淡出；**只有下滑或滚回
  顶部才回来**——停手不自动弹回，读长清单时右下角不会一直飘着两块东西。
- **选择模式一律显示**：批处理条不能藏在屏外。
- 覆盖页（[主线覆盖页](mainline.md) / 编排与支线共用的那一块，[今日编排](plan.md)）盖住整块面板，那几页本来
  就看不清双钮。


## 过渡时长一览

面板里的动画参数散在各处，这张表是唯一能一眼看全的地方——改了哪个数，
回来改表中那一行。

| 过渡 | 时长 | 曲线 | 代码位置 |
|---|---|---|---|
| 面板滑入 / 滑出（应用内壳，遮罩同步） | 240ms | easeOutCubic | `android_shell.dart` |
| 跟手松手后补满 / 滑回（两个宿主同一档） | 60–220ms（`60 + 140 × 剩余行程`） | easeOutCubic | `android_shell.dart`、`overlay_panel_shell.dart` |
| 跳页（点页序圆点 / 通知定位） | 260ms | easeOutCubic | `side_panel.dart`、`android_shell.dart` |
| 页名切换 | 180ms | 线性淡入淡出 | `side_panel.dart` |
| 页序圆点换色 | 220ms | easeOutCubic | `side_panel.dart` |
| 主线与支线覆盖页进 / 退（『返回』与返回键） | 260 / 200ms | easeOutCubic / easeInCubic | `side_panel.dart` |
| 覆盖页上滑退出（跟手段） | 1:1 跟手，不插值 | — | `side_panel.dart`、`mainline_panel.dart` |
| 覆盖页上滑退出（松手后补满 / 弹回） | 200ms | easeOutCubic | `side_panel.dart` |
| 编排与支线共用的覆盖页松手补满 / 弹回（进、出两向） | 200ms | easeOutCubic | `side_panel.dart` |
| 今日编排覆盖页"展开即落位" | 不播，当帧全开 | — | `side_panel.dart` |
| 主线覆盖页内翻页（`1/2`、记录页下半区右滑） | 240ms | easeOutCubic | `mainline_panel.dart` |
| 快记从方块展开成输入框 | 360ms（前 60% 走位、后 40% 展开） | 两段 easeOutCubic | `side_panel.dart` |
| 右下角双钮 ↔ 批处理条（选择模式进出） | 160ms | 默认淡入淡出 | `panel_dock.dart` |
| 右下角双钮上滑收起 / 回位 | 180ms | easeOutCubic | `panel_dock.dart` |

表里只有主线覆盖页进出不对称：进比退慢，因为进场要看清东西从哪儿来，
退场只是让位。

## 6.5 空状态与首次引导

- **首次拖出侧边栏**：一次性五步气泡引导——拖出展开 / 左右横滑翻页 /
  右下角两个钮（「+」新建、「日历」看月历）/ 拖到顶再拐个弯 = 快记（[快记](quick-note.md)，
  文案注明"悬浮把手上"：应用内壳也弹同一份引导，但那边没有这个手势，不注明会误导）/
  今日页滚到顶再往下拉 = 今日编排（[今日编排](plan.md)）；
  设置里可重看；
- 今日清单空："今天清单是空的"，附快捷按钮『从池子随机挑一件』（等价手动挑）；
- 任务池空："池干水清"；灵感空态见 [灵感页](notes.md)；已完成空："还没有完成的事"。
