# 6.12 支线（今日页日期行 → 文件夹视图）

**一句话**：把任务按"线"归堆。一条支线是一个文件夹，里面装的是从今日清单和任务池挑来的
**真实任务**——能勾、能点开、改了跟着变。

## 入口

- 今日清单**顶部日期那一行的右端**有一颗支线按钮（分叉图标）。
- 点它打开的是**编排那一块覆盖页**，落在支线视图（[今日编排](plan.md) 的页头有两段）。
- 桌面左栏是同一份面板，按钮在同一处、行为一致；桌面没有"进出"这一维，打开就是换视图。

## 与编排同页不同源

- 同一块覆盖页、同一套进出动画与返回键裁决（[今日编排](plan.md)）。**数据完全无关**：
  在支线里加一条，时间轴上不出现，反过来也一样。两个视图唯一的接触点是候选都来自
  今日清单与任务池。
- 页头第一行：返回、两段切换「编排」「支线」、右端计数（编排「N 项」、支线「N 条线」）。
  第二行那三段日期**只在编排视图**出现——支线不分天。
- **落哪个视图由入口决定**：今日页到顶下拉 → 编排；日期行按钮 → 支线。页内切换只在这一次
  打开里有效，退出再进来重新按入口算。
- 退出照旧三条路：左上返回、系统返回键、列表滚到底再继续上滑（与编排同一个判据：
  只在"末尾之后"算退出）。

## 文件夹

- 一条支线是一张卡片：头部一行文件夹图标 + 名字 + `2/5` 进度 + 折叠箭头。点头部折叠 / 展开，
  **默认收起**（一页上只有文件夹名，装得下更多条）；折叠状态不落盘，下次进来又是全收起。
  例外是刚新建的那条：建完自动展开并把候选框摆出来，否则刚建的东西看不见。
- **长按卡片头**弹菜单：改名、删除。删除只删这张分组，任务一件都不动。
- 展开后是任务行：左边勾选框、中间标题、右边状态（逾期橙红点、今天该响的时刻）。
  逾期、弱化这些状态沿用今日清单的同一套色与同一套判据（[今日清单页](today.md)）。
- **点行**开那一件的详情卡（与今日清单同一张），改期、推迟、删除都在那儿；
  **点勾**就是完成那个任务——日历的完成点、已完成页、池子统计全部跟着变。
- **拖动**改这条支线里的顺序，松手整份一次落盘。
- **已完成沉到卡片末尾**：划掉的行弱化显示在未完成之后；取消勾选回到原位。实现上只存
  一个全序（文件里的行序），渲染时分两段——取消勾选不必记"原来在第几位"。
- 全部干完的卡片，进度标成强调色。**不提供归档动作**，也就没有"已归档"折叠区可恢复。
- 同一件任务可以同时出现在多条支线里：完成它，几处一起变。支线之间互不排挤。

## 添加

- 每张卡片末尾一行虚线加号『添加任务』，点开就地展开候选框：**今日清单**（挂起 / 逾期 /
  固定 / 可推 / 被挑 / 散件，按清单顺序）与**任务池**（计划段、散件段，按整理序），
  输入框里的字用来筛，最多六条。
- 已经在这条支线里的候选标勾、**不可点**（同一行不出现两次）；已经在别的支线里的照常可点，
  右侧用弱色写明它在哪条线——允许重复，但让人看得见。
- **例行实例不进候选**：那是当天的实例，明天就不在了，挂进来只会立刻变成失效引用。
- **候选只给挑，不给写**：这一页没有"新建任务"的输入。
- 页底一行『新建支线』：就地展开一个输入框，回车建一张空卡片，随即展开它的候选框。
  空卡片在文件里留着，不因为没内容被清掉。

## 不做的

- 不分天、不排时刻、不响提醒、不进调度、不占工时——它是分组，不是第二本账。
- 不靠标题认人：文件里那一行也写着标题，但只给人读，界面显示的一律取任务的实时值
  （[支线文件](../formats/branch.md)）。

## 空态

一条支线都没有时：分叉图标 + 一句"把任务按线归堆" + 『新建支线』按钮。
今日清单和任务池都空时一样能建线，只是候选框里没东西可挑——建一条空线等着，
建任务的地方在别的页。
