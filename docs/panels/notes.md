# 6.2 灵感页

- 数据源：用户在 Obsidian 维护的一篇 Markdown（文件名随意，路径设置里可配，[UI 文档](../ui-interaction.md) §9 第 5 条）；
  App 与 Obsidian **读写同一份文件**——连接形式仍然只是"多一个入口"，
  不做插件、不接管 vault。
  - 路径必须是**真实文件路径**（`/storage/…/灵感.md`）：安卓选文件走原生 SAF，把
    documentId 换成真实路径后才落进输入框，光标停在末尾（先看到的是文件名，不是前缀）；
    换不出来（从云端或"最近"里挑到的文档）只能手输。App 缓存里的副本算不上路径——
    写进去的是副本，Obsidian 那份就永远不动；
  - 选的不是 `.md`：弹一句提示，原路径不变；
- **提取显示规则**：
  - 显示 **frontmatter 闭合 `---` 之后、到下一个 `---` 之间**的那段正文（不是 YAML 本身）；
  - 行内出现 `[[` 的**整行屏蔽不显示**（过滤 wiki 链接行）；
  - 正文里没有第二个 `---` → 取到**文件末尾**；
  - 空状态：文件未配置/找不到 → "未找到灵感，去设置选择文件"；整段被 `[[` 过滤光 → "这一段没有可显示的内容"。
- **只读态的呈现**（编辑态不受影响，见下条）：
  - 行内：`**粗**`、`*斜*` / `_斜_`、`***粗斜***`、`~~删除线~~`、`` `行内代码` ``；
  - 块级：`#` 到 `######` 的标题、`-`/`*`/`+` 无序列表（按缩进分层）、`1.` 有序列表、`>` 引用、
    围栏代码块（三个反引号）；
  - 链接 `[文字](url)` **只留文字**、染强调色，不接点击——面板窄，误触跳出浏览器比不做更烦；
    图片不出图，只把 `![说明](路径)` 里的说明当文字显示；裸 URL 不做识别；
  - **不做**表格、脚注、HTML 内嵌，以及 `==高亮==` / `%%注释%%` 这类 Obsidian 扩展——
    写了什么样就显示什么样；
  - 空行分段；段内保留手写的换行，不按段落合并；
  - 定界符内侧紧贴空格不算强调（`2 * 3` 里的星号原样显示），`snake_case` 里的下划线同理；
  - 样式只加在**显示**上，写回文件的仍是你写的那份原文，不做"规范化"。
- **编辑**：App **可就地改正文段**，frontmatter 一个字符都不动。
  - 入口：页头的铅笔图标（页名就叫"灵感"，不再带"（只读）"后缀）；点了进**编辑态**——
    正文换成占满页面的多行输入框，页头按钮换成『保存』『取消』，其余不变；
  - **编辑态与只读态看到的是同一份**：被 `[[` 屏蔽的行（典型是正文最上面那行相关链接）
    编辑框里也不出现、也改不了；保存时按原行号原样插回正文段，这几行不会因为保存丢掉。
    眼不见的行既然不给改，也不该在保存时被悄悄抹掉——插回这一步就是为它兜底；
  - **保存 = 用编辑内容替换正文段**：frontmatter、正文段前后的全部内容（含分隔用的
    `---` 与其后段落）逐行原样保留；文件原有的换行风格（CRLF/LF）与"是否以换行结尾"
    也照旧，不因为保存把整个文件重排一遍；
  - 编辑态是纯文本，不渲染样式（样式只在只读态）；保存后回到只读态，按新内容重新过滤并呈现；
  - **可编辑的前提**：路径已配置且文件存在。未配置/找不到只给空态提示，不给编辑
    （App 不替人创建文件）；frontmatter 未闭合（只有开头的 `---` 没有闭合）属于结构
    坏掉的文件，同样不给编辑——那时"正文段"的边界本身是不确定的；
  - 局限（登记在此，不另做）：写盘是"读—改—写"，若 Obsidian 此刻也在改同一个文件，
    以 App 这次保存为准（Obsidian 自己的历史还在）；App 不做锁、不做合并。
- 本页**不摆右下角双钮**（[面板与页面](README.md)）：这一页是读正文的地方，两颗钮压在
  字上，又没有可加的东西；要新建从别的页进。
