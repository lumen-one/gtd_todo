# 支线插座

支线（任务分组）住在独立的 `支线.md` 里，一个文件装全部支线；条目是任务引用，不是任务。

**BranchRepository / BranchCodec**：一条支线 = 名字 + 一串有序的任务 id。段序就是卡片顺序，
段内行序就是任务顺序（[格式](../formats/branch.md)）。与任务、周期、主线、编排四套都不相交
——支线不写 sidecar、不进调度、不占工时、不响提醒，`.gtd/` 里没有它的痕迹。
实现：`domain/branch.dart` + `repository/{branch_codec,branch_repository,
markdown_branch_repository}.dart` + `application/branch_service.dart`。

**每条命令都读整份、改一段、整份写回**：两个引擎（应用内 / 悬浮面板）可能同时写同一个文件，
读一遍再改能把另一个引擎刚写的别的段带上，不至于被本地旧内存态抹掉（与主线、编排同一套）。
定位用段序下标而不是内容指纹——命令与界面读的是同一份盘上数据，中间没有"先读盘再按内容找回"
那一步，也就没有主线记录那种下标失效问题。

**标题在保存时按任务重写**：读进来之后标题字段以 `TaskService` 里那一件的实时值为准，
落盘时写新的；指不到任务的 id 原样保留，不删行、不改写（[格式](../formats/branch.md)）。
所以支线与任务之间只有一条单向依赖：支线读任务，任务不知道支线存在。
